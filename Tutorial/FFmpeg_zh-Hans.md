# FFmpeg 下载

FFmpeg 可以到此网站下载 : https://ffmpeg.org/download.html

官网没有提供直接编译后的程序, 如果你想自己编译那么可以下载源代码编译  
如果你不希望自己编译请继续往下看

# 已编译的分支下载

*粗体为个人推荐的下载方式*

## Linux
- Package
    - `Debian` https://tracker.debian.org/pkg/ffmpeg
    - `Debian` https://www.deb-multimedia.org/
    - `Ubuntu` https://launchpad.net/ubuntu/+source/ffmpeg
    - `Fedora` `Red Hat Enterprise Linux` https://rpmfusion.org/
- Static
    - `32-bit and 64-bit for kernel 3.2.0 and above` https://johnvansickle.com/ffmpeg/
    - `64-bit static and shared builds` https://github.com/BtbN/FFmpeg-Builds/releases
