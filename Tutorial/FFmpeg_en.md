# FFmpeg Download

You can download FFmpeg from this website: [https://ffmpeg.org/download.html](https://ffmpeg.org/download.html).

The official website does not provide pre-compiled binaries. If you wish to compile it yourself, you can download the source code and compile it.  
If you do not want to compile it yourself, please continue reading below.
